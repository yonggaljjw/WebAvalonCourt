# Frontend 테스트 — 화면을 띄우기 전 확인하는 동작

Node.js 내장 `node:test`를 사용하며 추가 테스트 프레임워크는 필요 없습니다. 프로젝트 루트에서 실행합니다.

```sh
node --test frontend/tests/*.test.js
```

| 파일 | 확인하는 동작 | 학습 포인트 |
|---|---|---|
| audio.test.js | 상태 변화에서 효과음을 고르는 transitionCue() | 입력/출력만으로 검사하는 순수 함수 |
| presentation.test.js | 공개 이벤트 선택·중복 억제·결과 우선순위 | 개인 정보가 공개 연출에 섞이지 않는지 검사 |
| audio-engine.test.js | 늦은 로딩·음소거·방 이동·소스 상한·종료 정리 | 가짜 Context와 지연 응답으로 비동기 경쟁 조건 재현 |

총 18개입니다. 가짜 오디오 객체로 검사하는 테스트는 실제 스피커 청취를 대신하지 않습니다. 실제 브라우저와 서버까지 확인한 범위는 루트 TEST_REPORT.md를 참고하세요.
