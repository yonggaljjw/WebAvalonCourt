# 이미지·음악 이용 정보

## 이미지

`frontend/public/assets/remaster/`의 이미지 24종과 축소/반응형 파생본은 이 프로젝트의 텍스트 명세를 바탕으로 ChatGPT 내장 이미지 생성 도구에서 제작한 결과물입니다. 공식 보드게임 카드나 로고를 입력 이미지로 사용하지 않았습니다. 임의로 CC0 또는 독점 권리가 보장된 이미지라고 표시하지 않으며 이용에는 사용한 서비스의 적용 약관이 따릅니다. 이 프로젝트는 공식 제품과 무관한 비공식 팬 구현입니다.

## 음악

아래 음악 원본은 OpenGameArt의 각 저작자 페이지에서 CC0 1.0 표시를 확인한 파일입니다. [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)에 따라 수정·재배포하며 의무는 없지만 크레딧을 유지합니다. 실행 파일은 44.1kHz 스테레오 OGG로 변환하고 음량을 정규화했습니다.

| 실행 파일 | 원곡 / 저자 | 출처 | 편집 |
|---|---|---|---|
| camelot.ogg | Medieval: The Bard’s Tale / RandomMind | https://opengameart.org/content/medieval-the-bards-tale | 제공된 loop 버전 |
| council.ogg | Medieval: The Old Tower Inn / RandomMind | https://opengameart.org/content/medieval-the-old-tower-inn | 제공된 loop 버전 |
| suspicion.ogg | Col Legno / Vehicle | https://opengameart.org/content/col-legno | 원곡 반복 |
| last-shadow.ogg | Cave Theme / HaelDB | https://opengameart.org/content/cave-theme | 원곡 반복 |
| dawn.ogg | New Sunrise / nene | https://opengameart.org/content/new-sunrise | 앞 16초·페이드 |
| fallen-crown.ogg | Cave Theme / HaelDB | https://opengameart.org/content/cave-theme | 앞 16초·페이드 |

악 종료 음악과 암살 음악은 같은 원곡을 공유하며 독립된 신곡으로 세지 않습니다. 효과음 WAV 11개는 외부 샘플을 사용하지 않고 파형과 난수로 합성 제작했습니다. 실제 오케스트라나 물체를 녹음한 소리로 표시하지 않습니다.

## 코드와 의존성

기존 저장소 코드와 각 의존성의 라이선스는 해당 원본의 조건을 따릅니다. 이 문서는 프로그램 전체에 새 라이선스를 부여하지 않습니다.
