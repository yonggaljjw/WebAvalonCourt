# `backend/app` 구조

`app`은 실제 FastAPI 애플리케이션 코드가 모인 Python 패키지입니다. `__init__.py`가 있기 때문에 Python이 이 디렉토리를 패키지로 인식합니다.

## 파일 역할

| 파일/폴더 | 역할 |
|---|---|
| `main.py` | ASGI 진입점. 앱 생성만 수행합니다. |
| `factory.py` | FastAPI 객체 생성, 미들웨어/예외 처리기/라우터 등록을 담당합니다. |
| `lifecycle.py` | 서버 시작·종료 때 DB 복원, 시계 태스크 시작/종료를 담당합니다. |
| `schemas.py` | Pydantic으로 HTTP 입력값의 형식과 범위를 검증합니다. |
| `state.py` | 현재 프로세스가 공유하는 방/소켓/Lock 상태입니다. |
| `core/` | 환경변수, DB, 보안처럼 게임과 무관한 기반 기능입니다. |
| `domain/` | 네트워크나 DB와 분리된 아발론 게임 규칙입니다. |
| `routers/` | 외부 요청이 처음 들어오는 API 진입점입니다. |
| `services/` | 세션, 방 조회, 브로드캐스트처럼 여러 곳에서 재사용하는 업무 로직입니다. |

## 설계 포인트

`main.py`에 모든 코드를 넣지 않고 **진입점 → 라우터 → 서비스 → 도메인/코어**로 분리했습니다. 이렇게 하면 게임 규칙을 테스트할 때 FastAPI나 DB를 띄우지 않고도 `Room` 객체만 테스트할 수 있습니다.
