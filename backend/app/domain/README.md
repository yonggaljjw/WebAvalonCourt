# `domain` — 아발론 게임 규칙

`game.py`는 이 프로젝트의 핵심입니다. FastAPI, WebSocket, MySQL을 전혀 몰라도 **게임 상태가 어떻게 바뀌어야 하는지**만 책임집니다.

## 핵심 객체

- `Player`: 한 참가자의 ID, 닉네임, 역할, 준비/연결 상태
- `Room`: 한 게임방 전체 상태. 현재 라운드, 대장, 원정대, 투표, 원정 결과 등을 보관합니다.
- `RuleError`: 잘못된 행동을 게임 규칙 오류로 표현하는 예외입니다.

## 상태 머신(State Machine)

아발론 진행은 다음 단계가 순환하는 상태 머신으로 볼 수 있습니다.

```text
lobby
  ↓ 시작
proposal ──팀 제안──> vote
  ↑                   ├─부결→ 다음 대장 → proposal
  │                   └─승인→ quest
  │                              ├─게임 계속→ proposal
  │                              ├─호수의 여인→ lady → proposal
  │                              └─성공 3회→ assassination
  │                                              ↓
  └──────────────────────────────────────────── ended
```

`Room.action()`은 사용자 행동을 받아 현재 `phase`에서 허용되는지 검증한 뒤 상태를 변경합니다. `Room.view()`는 서버 내부의 비밀 정보를 그대로 보내지 않고 **해당 플레이어가 볼 수 있는 정보만** 만들어 반환합니다.
