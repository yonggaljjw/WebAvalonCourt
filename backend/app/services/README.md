# `services` — 재사용되는 업무 로직

라우터와 도메인 사이에서 여러 곳이 공통으로 쓰는 기능을 모았습니다.

## 파일별 역할

- `session_service.py`: 익명 사용자 세션 생성/조회
- `room_service.py`: 방 찾기, 방 설정 검증, 사용자가 다른 방에 있는지 확인
- `realtime.py`: WebSocket 브로드캐스트와 1초 주기의 서버 시계 처리

## Service Layer란?

라우터에 DB 조회, 검증, 브로드캐스트 같은 코드가 계속 늘어나면 URL 처리 함수가 너무 복잡해집니다. 반복되거나 하나의 책임으로 묶을 수 있는 로직을 `services`로 옮기면 라우터는 **“요청을 받고 어떤 서비스를 호출할지”**에 집중할 수 있습니다.
