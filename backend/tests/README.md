# Backend 테스트

`pytest`로 게임 규칙과 API 동작을 검증합니다.

- `test_game.py`: FastAPI/DB 없이 `Room` 객체만 이용하는 **단위 테스트**입니다.
- `test_api.py`: FastAPI `TestClient`와 WebSocket까지 사용해 실제 요청 흐름을 확인하는 **통합 테스트**입니다.

## 테스트를 읽으면 좋은 이유

테스트는 “이 함수가 원래 어떻게 동작해야 하는가?”를 가장 짧게 보여주는 실행 가능한 명세입니다. 예를 들어 7명 이상 4차 원정의 실패 조건, 5회 연속 부결, 암살 결과 등이 테스트 이름으로 드러납니다.
